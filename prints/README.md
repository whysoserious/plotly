# Print comparisons

Photographs and scans of test prints, so a claim about the paper can be checked
instead of remembered. Every artefact in this investigation has sat close to the
threshold of visibility, and single-sheet eyeballing has contradicted itself
five times (DESIGN.org §2.9a).

Name a file for what it is a print *of*, and what was different about it:

    hook-test-dwell.jpg     pen_fence = "dwell"
    hook-test-off.jpg       pen_fence = "off"   (the positive control)

A pair differing in one setting, on the same paper with the same pen, beats any
number of single sheets.
